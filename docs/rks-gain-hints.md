# v1.6.0 谱面库 RKS 提升提示

本地谱面库的每张卡片在准确率下方增加一行。提示使用当前 RKS 设置选定的定数、准确率和参与状态；额外成绩条目也参与 Bn/AP 门槛计算。筛选、收藏或排序不改变完整谱面库的 Bn 归属。

| 条件（按优先级） | 显示 |
| --- | --- |
| 当前有效准确率 ≥ 100% | 金黄色 `φ` |
| 当前准确率 < 100%，提到 100% 仍不能提高当前 RKS | 绿色 `√` |
| 已在 Bn，或启用了 Bn 且尚未填满 | `↑` |
| 不在 Bn，能通过提升准确率超过末名 | `↑n.nn%` |

末名使用 Bn 的最后一名，不把独立 AP 组的最后一名当作 Bn 门槛。同分时沿用实际 Bn 的确定性排序。数字表示提升后需要达到的绝对准确率，例如从 98% 需要提升至 99.23%，显示 `↑99.23%`。单独的 `↑` 表示原先零增量提示的情况。

单谱等效 RKS 为 `定数 × ((准确率 − 55) / 45)²`，低于 70% 时为 0。对满员 Bn 反解门槛后，选择能**严格超过**末名的最小两位小数绝对准确率，并代回公式校验。因此恰好持平时会继续加 0.01 个百分点。目标准确率最多取 100.00%；即使当前准确率有更多小数位，显示的目标本身也必须能够严格过线。

当最佳成绩数量为 0 时，只根据 AP 组计算：达到 AP 可以提升 RKS 则显示 `↑100.00%`；否则显示绿色 `√`。Bn 无法进入但 AP 组仍能提升 RKS 时，也采用这一规则。两组数量同时为 0 的非法设置不会造成除零；设置界面仍禁止保存该配置。

未游玩谱面按当前 0% 计算提示，不写入成绩。未勾选参与 RKS 的谱面显示 `√`（100% 仍优先显示 `φ`）；AI 定数尚未就绪时显示 `—`，就绪后重新计算。修改定数、准确率、参与状态、成绩或 Bn/AP 数量后，提示随 RKS 一起刷新。

本功能不修改判定、真实成绩、谱面文件或上传逻辑。
